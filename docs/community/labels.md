# Issue labels

Created once on the repository (`gh label create ...`, see publication-checklist.md).

| label | colour | meaning |
|---|---|---|
| `deletion-guarantee` | `b60205` | A takedown not honoured, or anything that could weaken that guarantee |
| `durability` | `d93f0b` | Acknowledged data could be lost |
| `consensus` | `d93f0b` | Raft, replication, leadership |
| `bug` | `d73a4a` | Something does not work as documented |
| `performance` | `fbca04` | Latency, throughput, memory; comes with a measurement |
| `enhancement` | `a2eeef` | A new capability |
| `api` | `1d76db` | HTTP or binary protocol, clients |
| `ops` | `5319e7` | Deployment, Docker, scripts, observability |
| `docs` | `0075ca` | Documentation |
| `good first issue` | `7057ff` | Self-contained, with pointers to the code |
| `help wanted` | `008672` | Larger, where outside expertise helps (RAG, governance, systems) |
| `needs-adr` | `c5def5` | Changes a format, the protocol or Raft: an ADR comes first |
| `triage` | `ededed` | Not looked at yet |
